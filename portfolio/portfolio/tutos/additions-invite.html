Installer les additions invité et partager un dossier

Les additions invité de VirtualBox améliorent l’affichage et permettent de copier-coller et de partager un dossier entre Windows et la machine Ubuntu.

Niveau : débutantHôte : Windows, invité : Ubuntu

Avant de commencer

  • Une VM Ubuntu démarrée et un compte avec sudo.

Les étapes

  1. Installer les additions

    Insérer l’image CD des Additions invité (menu Périphériques), monter le DVD, ouvrir un terminal dans son dossier et lancer le script. Redémarrer ensuite.

    sudo ./VBoxLinuxAdditions.run
sudo reboot

  2. Activer le presse-papiers

    Périphériques, Presse-papier partagé, Bidirectionnel. Inutile d’activer le glisser-déposer avec un hôte Windows.

  3. Créer et déclarer le dossier partagé

    Sur Windows, créer C:\VirtualBox\votreLogin\share. Dans la VM : Périphériques, Dossiers partagés, Réglages, ajouter ce dossier avec Montage automatique et Configuration permanente.

  4. Monter le partage dans Ubuntu

    On crée un dossier et on y relie le partage.

    mkdir $HOME/partage
sudo mount -t vboxsf share $HOME/partage

Vérifier que ça marche

Test :

echo bonjour > $HOME/partage/test.txt

Le fichier test.txt apparaît dans le dossier Windows, et toute modification est visible des deux côtés.

À retenir

  • Le copier-coller se teste dans les deux sens.
  • Le dossier partagé évite clé USB et téléchargement.
