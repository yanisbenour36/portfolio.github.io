Linux : gérer utilisateurs, groupes et droits

Sous Linux, chaque personne a son compte et ses droits. Ce tuto crée des comptes, les range dans un groupe, puis donne juste le droit nécessaire sans en faire des administrateurs.

Niveau : débutantSystème : Ubuntu

Avant de commencer

  • Une machine Ubuntu et un compte qui peut utiliser sudo.
  • Les mots de passe user1 et user2 servent à l’entraînement uniquement.

Les étapes

  1. Savoir qui vous êtes

    L’UID est le numéro unique de votre compte. Le premier compte créé à l’installation a l’UID 1000, le suivant aura 1001.

    id -u
id

  2. Regarder les trois fichiers clés

    passwd (les comptes) et group (les groupes) sont lisibles par tous. shadow contient les empreintes des mots de passe : seul root le lit, donc sudo est nécessaire.

    cat /etc/passwd
cat /etc/group
sudo cat /etc/shadow

  3. Créer un groupe et deux utilisateurs

    Le système demande un mot de passe pour chaque compte. Vérifiez avec id user1 : le groupe principal doit être invite.

    sudo addgroup invite
sudo adduser --ingroup invite user1
sudo adduser --ingroup invite user2

  4. Se mettre à la place de user2

    Le tiret après su charge l’environnement complet de user2. La lecture des journaux est refusée, et sudo aussi : user2 n’est pas dans le fichier sudoers.

    su - user2
echo $USER
cat /var/log/syslog
sudo cat /var/log/syslog

  5. Donner un droit précis grâce à un groupe

    Le groupe adm permet de lire les journaux système, sans donner les pleins pouvoirs. Quittez user2, ajoutez-le au groupe, puis reconnectez-vous.

    exit
sudo adduser user2 adm
su - user2
cat /var/log/syslog

Vérifier que ça marche

Pour voir les groupes de user2 :

id user2

La sortie doit lister les groupes invite et adm. Lire le journal fonctionne sans sudo, mais sudo reste refusé.

À retenir

  • root a tous les droits ; sudo prête ces droits pour une seule commande et laisse une trace.
  • Principe du moindre privilège : on donne seulement ce qui est nécessaire.
  • Un groupe permet de donner le même droit à plusieurs personnes d’un coup.
