Sécuriser un serveur web : HTTPS, PHP, MariaDB et phpMyAdmin

HTTPS chiffre les échanges entre le navigateur et le serveur. Ce tuto ajoute HTTPS à Apache, puis PHP, la base de données MariaDB et l’interface phpMyAdmin.

Niveau : intermédiairePrérequis : tuto Apache

Avant de commencer

  • Un Apache fonctionnel et un site monsite.fr (voir le tuto Apache).

Les étapes

  1. Activer SSL et créer un certificat de test

    Un certificat auto-signé suffit pour s’entraîner ; en vrai on utilise Let’s Encrypt. Indiquer monsite.fr comme Common Name.

    sudo a2enmod ssl
sudo systemctl restart apache2
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout /etc/ssl/private/apache-selfsigned.key -out /etc/ssl/certs/apache-selfsigned.crt

  2. Créer le VirtualHost HTTPS

    Fichier /etc/apache2/sites-available/monsite-ssl.conf :

    <VirtualHost *:443>
  ServerName monsite.fr
  DocumentRoot /var/www/mon_serveur
  SSLEngine on
  SSLCertificateFile /etc/ssl/certs/apache-selfsigned.crt
  SSLCertificateKeyFile /etc/ssl/private/apache-selfsigned.key
</VirtualHost>

  3. Activer et tester

    L’avertissement du navigateur est normal avec un certificat local.

    sudo a2ensite monsite-ssl.conf
sudo apache2ctl configtest
sudo systemctl restart apache2

  4. Installer PHP

    PHP fabrique les pages dynamiques côté serveur. Créez info.php contenant <?php phpinfo(); ?> pour tester.

    sudo apt install php libapache2-mod-php php-mysql
sudo systemctl restart apache2

  5. Installer et sécuriser MariaDB

    mysql_secure_installation supprime les accès dangereux par défaut. Choisissez votre propre mot de passe.

    sudo apt install mariadb-server
sudo mysql_secure_installation
sudo mysql
CREATE DATABASE testweb;
CREATE USER 'webuser'@'localhost' IDENTIFIED BY 'MOT_DE_PASSE';
GRANT ALL PRIVILEGES ON testweb.* TO 'webuser'@'localhost';

  6. Installer phpMyAdmin et le limiter

    Ajouter « Require local » dans /etc/apache2/conf-available/phpmyadmin.conf pour n’autoriser que la machine locale.

    sudo apt install phpmyadmin
sudo ln -s /usr/share/phpmyadmin /var/www/html/phpmyadmin
sudo systemctl reload apache2

Vérifier que ça marche

Dans le navigateur :

https://monsite.fr

Le site s’ouvre en HTTPS, info.php s’affiche et phpMyAdmin répond en local.

À retenir

  • HTTPS apporte confidentialité, intégrité et authentification.
  • Architecture : Apache sert, PHP calcule, MariaDB stocke ; phpMyAdmin les administre.
  • Choisissez toujours un mot de passe fort, jamais celui d’un exemple.
