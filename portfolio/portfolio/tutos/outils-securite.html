Installer les outils de sécurité d’un technicien réseau

Six outils essentiels : scanner un réseau (Nmap), analyser le trafic (Wireshark), bloquer les attaques (Fail2ban), détecter les intrusions (Suricata), simuler un réseau (Packet Tracer) et tester une application web (Burp Suite).

Niveau : intermédiaireSystème : Ubuntu

Avant de commencer

  • Ubuntu avec Internet. N’utilisez ces outils que sur vos propres machines.

Les étapes

  1. Nmap

    sudo apt install nmap
nmap --version
nmap 127.0.0.1

  2. Wireshark

    Répondre Oui à la question sur la capture sans être root, puis ajouter son compte au groupe.

    sudo apt install wireshark
sudo usermod -aG wireshark $USER

  3. Fail2ban

    Surveille les journaux et bannit les adresses qui multiplient les tentatives de connexion.

    sudo apt install fail2ban
sudo fail2ban-client status
sudo fail2ban-client status sshd

  4. Suricata

    Absent des dépôts standard : on ajoute le dépôt officiel de l’éditeur.

    sudo add-apt-repository ppa:oisf/suricata-stable
sudo apt update
sudo apt install suricata
suricata --build-info

  5. Packet Tracer (paquet .deb)

    À télécharger sur Cisco NetAcad. En cas d’erreur de dépendances, la seconde commande les répare.

    sudo dpkg -i ~/Téléchargements/packettracer-version.deb
sudo apt install -f

  6. Burp Suite Community (archive)

    Télécharger l’installateur sur le site officiel, le rendre exécutable puis le lancer.

    cd /opt
sudo chmod +x burpsuite_community_linux.sh
sudo ./burpsuite_community_linux.sh

Vérifier que ça marche

Pour vérifier :

nmap --version

Chaque outil se lance sans erreur.

À retenir

  • Sur un serveur en production : Fail2ban et un détecteur d’intrusion comme Suricata. Nmap, Wireshark et Burp servent surtout à l’audit et au diagnostic.
  • Un dépôt tiers permet d’obtenir un logiciel récent absent des dépôts standard.
