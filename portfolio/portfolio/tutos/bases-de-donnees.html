Bases de données : types de champs et dictionnaire de données

Avant de créer une base, on liste les données et on choisit le bon type pour chacune. Cet outil, le dictionnaire de données, évite des erreurs comme perdre le zéro d’un numéro.

Niveau : débutantNotions : SGBDR, table, clé primaire

Avant de commencer

  • Vocabulaire : une table est un tableau (colonnes = champs, lignes = enregistrements). Une clé primaire identifie chaque ligne ; une clé étrangère renvoie vers la clé primaire d’une autre table.

Les étapes

  1. Choisir un type par donnée

    Taille (1,88 m) : décimal. Temps, vitesse, distance : nombres décimaux. Numéro de département : texte court, car 01 perdrait son zéro en nombre, et 2A, 2B ou 971 existent.

  2. Écrire le dictionnaire des départements

    num_dep       CHAR(3)       numéro (01, 2A, 971)
nom_dep       VARCHAR(50)   nom du département
superficie    INT           km2
population    INT           habitants
densite       DECIMAL(6,1)  habitants par km2

  3. Écrire le dictionnaire d’une fiche d’identité

    Une date se stocke en type DATE, un téléphone en texte (pour garder le zéro initial).

    nom            VARCHAR(50)
date_naissance DATE
nationalite    VARCHAR(30)
taille         DECIMAL(3,2)
poids          DECIMAL(5,1)
adresse        VARCHAR(100)
telephone      CHAR(10)
email          VARCHAR(100)

Vérifier que ça marche

Pour vérifier :

Chaque champ a un type adapté, une longueur et une description.

À retenir

  • Types courants : texte, entier, décimal, date et heure, booléen.
  • L’âge se calcule depuis la date de naissance : ne le stockez pas.
