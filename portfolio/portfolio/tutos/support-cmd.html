Les commandes CMD du support informatique

Face à un poste lent ou un utilisateur bloqué, un technicien commence par quelques commandes. Voici les essentielles, rangées par situation, avec la bonne réponse aux exercices.

Niveau : débutantSystème : Windows

Avant de commencer

  • Un terminal CMD. Pour les comptes et les réparations, ouvrez-le en administrateur.

Les étapes

  1. Poste lent : voir les processus

    Repérez un programme bloqué ou trop gourmand.

    tasklist
systeminfo
hostname

  2. Qui suis-je ? Quel domaine ?

    Utile quand un utilisateur pense ne pas être reconnu.

    whoami

  3. Problème réseau

    ipconfig /all montre IP, DNS, passerelle et MAC ; netstat -ano relie chaque connexion à un PID ; arp -a affiche les couples IP / MAC connus.

    ping 8.8.8.8
tracert srv-pedago
ipconfig /all
netstat -ano
arp -a

  4. Gérer les comptes

    Supprimer le compte local d’un ancien employé :

    net user
net user ancienemploye /delete
net localgroup administrators

  5. Réparer le système

    sfc répare les fichiers Windows abîmés ; chkdsk C: /f analyse et répare le disque.

    sfc /scannow
chkdsk C: /f
taskkill /PID 1234
tree

  6. Session et accès distant

    Connecter un partage réseau sur la lettre Z :

    mstsc
net use Z: \\SERVEUR\PARTAGE
logoff

Vérifier que ça marche

Pour l’inventaire d’une salle :

hostname

Relevez le nom de chaque poste avant une mise à jour.

À retenir

  • tracert srv-pedago affiche tous les sauts jusqu’au serveur (l’option -h limite seulement leur nombre).
  • Supprimer un compte se fait avec net user nom /delete, pas avec taskkill.
