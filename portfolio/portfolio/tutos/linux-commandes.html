Linux : les commandes fondamentales du shell

Le shell est l’interface en ligne de commande de Linux. Voici les commandes de base pour s’informer, se déplacer, créer, copier, lier et comparer des fichiers.

Niveau : débutantSystème : Ubuntu

Avant de commencer

  • Un terminal. Le symbole $ est l’invite : ne le tapez pas. La touche Tab complète les noms ; les flèches haut et bas rappellent l’historique.

Les étapes

  1. S’informer sur le système

    uname -a
whoami
date
cal

  2. Se déplacer

    ~ désigne votre dossier personnel, .. le dossier parent, . le dossier courant.

    pwd
cd ~
cd ..
ls -l

  3. Créer

    touch crée un fichier vide, cat l’affiche.

    mkdir tp
cd tp
touch a.txt
echo bonjour > a.txt
cat a.txt

  4. Copier, déplacer, supprimer

    cp a.txt b.txt
mv b.txt c.txt
rm c.txt

  5. Créer des liens

    ln -s crée un raccourci (lien symbolique) vers un fichier.

    ln a.txt lien-dur.txt
ln -s a.txt raccourci.txt

  6. Comparer deux fichiers

    diff a.txt lien-dur.txt

Vérifier que ça marche

Pour vérifier :

ls -l

Le raccourci s’affiche avec une flèche vers a.txt.

À retenir

  • Chaque commande suit la forme : commande, options, arguments.
  • Utilisez man commande pour l’aide complète.
