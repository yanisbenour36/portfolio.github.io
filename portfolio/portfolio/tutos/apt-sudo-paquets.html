Linux : sudo et gestion des logiciels avec apt

On évite de travailler en root. Avec sudo, on obtient les droits administrateur le temps d’une commande, et apt installe, met à jour et supprime les logiciels.

Niveau : débutantSystème : Ubuntu

Avant de commencer

  • Un compte Ubuntu avec sudo et une connexion Internet.

Les étapes

  1. Mettre le système à jour

    update rafraîchit la liste des logiciels disponibles, dist-upgrade met à jour ce qui est installé.

    uname -r
sudo apt update
sudo apt dist-upgrade

  2. Chercher un paquet installé

    dpkg -l liste les paquets installés ; grep filtre.

    dpkg -l | grep firefox

  3. Installer un logiciel

    apt installe aussi les dépendances nécessaires, qu’il affiche avant d’installer.

    apt search vim-gui-common
sudo apt install vim-gui-common

  4. Retrouver à quel paquet appartient un fichier

    Utile en administration pour savoir d’où vient un fichier de configuration.

    dpkg -S cheese.conf

  5. Supprimer

    remove retire le logiciel mais garde sa configuration ; purge supprime aussi la configuration.

    sudo apt remove cheese
sudo apt purge cheese

Vérifier que ça marche

Pour vérifier :

dpkg -l | grep cheese

Après purge, le paquet n’apparaît plus.

À retenir

  • Une version se lit majeur.mineur.micro (2.5.21).
  • apt est l’outil moderne qui regroupe apt-get et apt-cache.
