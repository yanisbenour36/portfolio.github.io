Installer un serveur web Apache et héberger un site

Un serveur web envoie des pages à un navigateur. Ce tuto installe Apache sur Ubuntu, vérifie qu’il fonctionne, puis héberge un second site sous son propre nom grâce à un VirtualHost.

Niveau : débutantSystème : Ubuntu en machine virtuelle

Avant de commencer

  • Une machine Ubuntu avec accès à Internet et un compte qui peut utiliser sudo.
  • Dans le TP, le nom du site est votre_login.fr ; ici, on utilise monsite.fr.

Les étapes

  1. Installer et démarrer Apache

    enable lance Apache automatiquement à chaque démarrage. Ouvrez ensuite http://localhost : la page « Apache2 Ubuntu Default Page » doit s’afficher.

    sudo apt update
sudo apt install apache2
sudo systemctl start apache2
sudo systemctl enable apache2

  2. Repérer où se trouve la configuration

    sites-available contient les sites possibles, sites-enabled les sites actifs (des liens vers les premiers). mods-available et mods-enabled font de même pour les modules.

    cd /etc/apache2
ls

  3. Créer votre site

    Apache travaille dans /var/www. Le lien symbolique permet de garder vos fichiers dans votre dossier personnel.

    mkdir ~/mon_serveur
nano ~/mon_serveur/index.html
chmod 755 ~/mon_serveur
sudo ln -s $HOME/mon_serveur /var/www/mon_serveur

  4. Donner un nom au site

    Sans vrai DNS, le fichier /etc/hosts dit à votre ordinateur que monsite.fr, c’est lui-même. Ajoutez cette ligne :

    sudo nano /etc/hosts

127.0.0.1  monsite.fr

  5. Écrire le VirtualHost

    Un VirtualHost décrit un site : son nom, son dossier et les accès autorisés. On copie le modèle par défaut puis on le modifie.

    cd /etc/apache2/sites-available
sudo cp 000-default.conf monsite.conf
sudo nano monsite.conf

<VirtualHost *:80>
  ServerName monsite.fr
  DocumentRoot /var/www/mon_serveur
  ErrorLog ${APACHE_LOG_DIR}/mon_serveur_error.log
  CustomLog ${APACHE_LOG_DIR}/mon_serveur_access.log combined
  <Directory /var/www/mon_serveur>
    Options FollowSymLinks MultiViews
    AllowOverride None
    Require all granted
  </Directory>
</VirtualHost>

  6. Activer le site et vérifier

    configtest doit répondre Syntax OK. Un avertissement sur le ServerName du serveur est sans gravité.

    sudo a2ensite monsite.conf
sudo apache2ctl configtest
sudo systemctl reload apache2

Vérifier que ça marche

Dans le navigateur :

http://monsite.fr

Votre page index.html doit s’afficher, et non la page par défaut d’Apache.

À retenir

  • Un seul Apache peut héberger plusieurs sites, chacun avec son VirtualHost.
  • Pour activer un site : a2ensite. Pour le couper : a2dissite.
  • Bonne pratique : retirer l’option Indexes qui affiche la liste des fichiers d’un dossier (fuite d’informations).
