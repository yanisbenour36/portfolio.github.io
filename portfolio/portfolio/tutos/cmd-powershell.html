CMD et PowerShell : organiser des dossiers et comparer les deux

Mission d’un technicien de lycée : préparer les espaces de travail des étudiants SISR et SLAM. On crée l’arborescence, on manipule des fichiers, et on compare CMD et PowerShell.

Niveau : débutantSystème : Windows

Avant de commencer

  • Ouvrez CMD (tapez cmd) et PowerShell (tapez PowerShell) dans le menu Démarrer.

Les étapes

  1. Créer les dossiers principaux

    La même action s’écrit différemment selon l’outil.

    CMD :
cd \
mkdir BTS_SIO TRAVAIL

PowerShell :
Set-Location C:\
New-Item BTS_SIO,TRAVAIL -ItemType Directory

  2. Créer les sous-dossiers

    SISR : systèmes, réseaux, sécurité. SLAM : code, base de données, documentation, tests. TRAVAIL : cours, TP, annexes, temp.

    mkdir BTS_SIO\SISR BTS_SIO\SLAM
mkdir BTS_SIO\SISR\SYSTEME BTS_SIO\SISR\RESEAUX BTS_SIO\SISR\SECURITE
mkdir BTS_SIO\SLAM\CODE BTS_SIO\SLAM\BD BTS_SIO\SLAM\DOC BTS_SIO\SLAM\TESTS
mkdir TRAVAIL\COURS TRAVAIL\TP TRAVAIL\ANNEXES TRAVAIL\TEMP

  3. Enregistrer un listing dans un fichier

    Le signe > écrit le résultat d’une commande dans un fichier, >> l’ajoute à la fin.

    cd BTS_SIO\SLAM\CODE
dir > liste1.txt
dir C:\Windows /o:s > liste2.txt
dir C:\Windows\*.txt > liste3.txt

  4. Copier, renommer, chercher

    find cherche un mot dans un fichier.

    copy liste*.txt C:\TRAVAIL\TEMP
ren liste1.txt file1.txt
copy file1.txt C:\TRAVAIL\fiche1.txt
dir >> C:\TRAVAIL\fiche1.txt
find "Win" C:\TRAVAIL\fiche1.txt

  5. Nettoyer

    rmdir /s supprime un dossier et tout son contenu : vérifiez le chemin avant.

    del file*
rmdir C:\TRAVAIL /s
dir C:\BTS_SIO /s

Vérifier que ça marche

Pour vérifier l’arborescence :

dir C:\BTS_SIO /s

Vous devez voir SISR et SLAM avec leurs sous-dossiers.

À retenir

  • Équivalences : dir = Get-ChildItem, cd = Set-Location, copy = Copy-Item, ren = Rename-Item, del = Remove-Item, find = Select-String.
  • PowerShell est plus puissant mais plus long à écrire ; CMD reste pratique pour les actions rapides.
