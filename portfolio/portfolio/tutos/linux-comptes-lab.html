Linux : créer et gérer des comptes avec useradd et chage

Gérer les utilisateurs et les groupes, c’est protéger les fichiers, partager un projet et savoir qui a fait quoi. Ce tuto couvre le cycle de vie d’un compte.

Niveau : débutantSystème : Ubuntu 24.04

Avant de commencer

  • Un compte avec sudo. Alice sert d’exemple.

Les étapes

  1. Créer un groupe et un compte

    -m crée le dossier personnel, -g donne le groupe principal.

    sudo groupadd projet_compta
sudo useradd -m -s /bin/bash -g projet_compta alice
sudo passwd alice

  2. Lire les fichiers de comptes

    passwd contient l’identité, shadow l’empreinte du mot de passe (réservée à root).

    grep alice /etc/passwd
sudo grep alice /etc/shadow

  3. Régler l’expiration du mot de passe

    chage -l affiche les règles, -M fixe la durée maximale en jours.

    sudo chage -l alice
sudo chage -M 90 alice

  4. Modifier un compte

    -aG ajoute à un groupe secondaire sans retirer les autres.

    sudo usermod -aG adm alice
id alice

  5. Supprimer un compte

    -r supprime aussi son dossier personnel.

    sudo userdel -r alice

Vérifier que ça marche

Pour vérifier :

getent passwd alice

Après suppression, la commande ne renvoie rien.

À retenir

  • Principe du moindre privilège : donner seulement les droits nécessaires.
  • Un groupe permet de partager un dossier sans tout ouvrir à tout le monde.
