CMD : administrer et diagnostiquer un poste Windows

Aller plus loin avec CMD : personnaliser la fenêtre, cacher un fichier, surveiller les processus et diagnostiquer le réseau comme un technicien.

Niveau : débutant à intermédiaireSystème : Windows

Avant de commencer

  • Ouvrez CMD en administrateur : Win + R, tapez cmd, puis Ctrl + Maj + Entrée.

Les étapes

  1. Vérifier l’environnement

    Affiche le dossier courant et la version de Windows.

    echo %CD%
ver

  2. Personnaliser la fenêtre

    color change les couleurs, prompt la présentation de la ligne de commande, title le nom de la fenêtre.

    color 0A
prompt $T [$P]$G
title Session_Admin_CMD

  3. Cacher un fichier

    L’attribut +H rend un fichier invisible dans dir ; l’option /A affiche tout, même les fichiers cachés.

    mkdir TP_CMD\Documents
echo CONTENU_SECRET > TP_CMD\Documents\fichier_cache.txt
attrib +H TP_CMD\Documents\fichier_cache.txt
dir TP_CMD\Documents
dir TP_CMD\Documents /A

  4. Repérer et fermer un processus

    Lancez le Bloc-notes et Paint, trouvez leur numéro (PID), puis fermez-les. /F force la fermeture, /T ferme aussi les processus enfants.

    tasklist | findstr "notepad mspaint"
taskkill /PID 1234 /F
taskkill /IM notepad.exe /T

  5. Tester la connexion réseau

    ping vérifie qu’une machine répond, tracert montre les routeurs traversés, pathping ajoute la perte de paquets, nslookup teste le DNS.

    ping 8.8.8.8 -n 4
tracert google.com
pathping google.com
nslookup google.com

  6. Voir les connexions actives

    netstat -ano liste les connexions, les ports et le PID du programme concerné.

    netstat -ano
netstat -an | find ":80"

Vérifier que ça marche

Pour le réseau :

ipconfig /all

Notez l’adresse MAC et si le DHCP est activé (attribution automatique de l’adresse IP).

À retenir

  • Le DHCP distribue automatiquement adresse IP, passerelle et DNS.
  • Un processus système fermé par erreur peut rendre Windows instable.
