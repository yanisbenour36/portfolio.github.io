Installer Xubuntu et créer ses partitions

Installer un système Linux dans une machine virtuelle en créant soi-même les partitions, pour comprendre à quoi sert chaque morceau du disque.

Niveau : débutantOutil : VirtualBox

Avant de commencer

  • Une VM VirtualBox démarrée sur l’ISO de Xubuntu.

Les étapes

  1. Lancer l’installation

    Choisir Français puis Installer Xubuntu, clavier « French ». Dans le TP on décoche les mises à jour pendant l’installation pour gagner du temps ; en réel, on les active.

  2. Créer la table de partitions

    Type d’installation : « Autre chose », sélectionner /dev/sda, puis Nouvelle table de partition.

  3. Créer quatre partitions

    /boot : 500 Mo, primaire, ext4. swap : 1500 Mo, primaire, espace d’échange. / : 15000 Mo, logique, ext4. /home : tout l’espace restant, logique, ext4.

  4. Faire vérifier avant de valider

    Toute erreur de partition peut effacer des données : demandez un contrôle avant « Continuer ».

  5. Finir l’installation

    Fuseau Paris, premier utilisateur du TP (nom SIO1, login sio1, mot de passe d’entraînement uniquement), puis redémarrer et appuyer sur Entrée.

Vérifier que ça marche

Pour vérifier :

df -h

Les points de montage /, /boot et /home apparaissent.

À retenir

  • /boot contient le démarrage, swap complète la RAM, / contient le système, /home les comptes des utilisateurs.
  • Séparer /home permet de réinstaller le système sans perdre ses fichiers.
