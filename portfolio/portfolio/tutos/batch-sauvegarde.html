Écrire un script Batch de sauvegarde avec journal

Des utilisateurs perdent leurs fichiers. On écrit un petit script que tout le monde peut lancer : il demande quoi sauvegarder, crée un dossier daté, copie les fichiers et garde un journal.

Niveau : intermédiaireLangage : Batch (.bat)

Avant de commencer

  • Un éditeur de texte (Bloc-notes) et un dossier de test avec quelques fichiers .txt.
  • Script proposé : essayez-le d’abord sur un petit dossier.

Les étapes

  1. Créer le fichier

    Ouvrez le Bloc-notes et enregistrez-le sous SauvegardeParam.bat (type : Tous les fichiers).

  2. Poser les questions

    set /p affiche une question et mémorise la réponse dans une variable.

    @echo off
set /p SRC=Dossier a sauvegarder :
set /p EXT=Type de fichiers (ex : txt) :
set /p DEST=Dossier de destination :

  3. Préparer le dossier daté

    On compose un nom avec la date et l’heure, puis on crée le dossier.

    set STAMP=%DATE:/=-%_%TIME:~0,2%h%TIME:~3,2%
set STAMP=%STAMP: =0%
set BK=%DEST%\Backup_%STAMP%
mkdir "%BK%"

  4. Copier et tenir le journal

    Le journal garde la date, l’utilisateur, ce qui a été copié, le nombre de fichiers et leur taille.

    echo === RAPPORT DE SAUVEGARDE === > "%BK%\log.txt"
echo Date : %DATE% %TIME% >> "%BK%\log.txt"
echo Utilisateur : %USERNAME% sur %COMPUTERNAME% >> "%BK%\log.txt"
xcopy "%SRC%\*.%EXT%" "%BK%\" /S /I /Y >> "%BK%\log.txt"
dir "%BK%\*.%EXT%" /S >> "%BK%\log.txt"

  5. Afficher le rapport

    pause laisse la fenêtre ouverte pour lire le résultat.

    type "%BK%\log.txt"
pause

Vérifier que ça marche

Lancez le script par double-clic :

SauvegardeParam.bat

Un dossier Backup_date est créé avec vos fichiers et un log.txt.

À retenir

  • Pour aller plus loin : robocopy gère mieux les fichiers verrouillés, et le Planificateur de tâches peut lancer le script chaque jour.
