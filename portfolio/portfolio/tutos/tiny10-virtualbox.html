Installer Windows 10 allégé (Tiny10) dans VirtualBox

Une machine virtuelle est un ordinateur simulé dans une fenêtre. Ce tuto installe VirtualBox, son pack d’extensions, puis Tiny10, une version légère de Windows 10.

Niveau : débutantOutil : VirtualBox

Avant de commencer

  • VirtualBox installé, l’Extension Pack correspondant à votre version et l’ISO de Tiny10.

Les étapes

  1. Ajouter le pack d’extensions

    Fichier, Paramètres, Extensions, puis + et choisir le fichier .vbox-extpack. Test : une clé USB apparaît dans Périphériques, USB.

  2. Créer la machine

    Nouvelle : nom Tiny10-Test, type Microsoft Windows, version Windows 10 (64-bit).

  3. Régler les ressources

    RAM : 2 Go minimum, 4 Go plus confortable, jamais plus de la moitié de la RAM de l’ordinateur. Processeurs : 2 cœurs. Disque : VDI, alloué dynamiquement, 32 Go.

  4. Monter l’ISO

    Paramètres, Stockage : cliquer sur le CD vide et choisir l’ISO. Dans Système, vérifier que le CD démarre avant le disque dur.

  5. Installer Windows

    Langue Français, clavier Français (AZERTY), Installer maintenant, puis « Personnalisée » et choisir le disque de 32 Go. Créer ensuite un utilisateur local.

  6. Installer les Additions invité

    Périphériques, Insérer l’image CD des Additions invité, lancer VBoxWindowsAdditions.exe dans la VM, puis redémarrer.

Vérifier que ça marche

Après redémarrage :

L’écran s’adapte à la fenêtre, le presse-papiers est partagé et la souris est fluide.

À retenir

  • VDI est le format natif de VirtualBox ; VHD ou VMDK servent à migrer vers Hyper-V ou VMware.
  • Une VM trop gourmande ralentit l’ordinateur hôte.
